# 🎬 Netflix Content Analysis Dashboard

## 📖 Project Overview

This project presents a comprehensive analysis of Netflix's content library using **SQL** and **Power BI**. The dashboard provides insights into content distribution, genre popularity, ratings, release trends, and geographical content availability.

The goal of this project is to transform raw Netflix data into meaningful business insights through data cleaning, SQL querying, data modeling, DAX calculations, and interactive visualizations.

---

## 🎯 Objectives

- Analyze Netflix content distribution across countries.
- Compare Movies and TV Shows.
- Identify the most popular genres and ratings.
- Analyze content release trends over time.
- Discover content growth patterns.
- Build an interactive dashboard for data-driven decision-making.

## 💡 Key Insights

- Movies make up the majority of Netflix content.
- The United States contributes the highest number of titles.
- Drama and International Movies are among the most popular genres.
- Netflix content has grown significantly in recent years.
- TV Shows have experienced steady growth alongside Movies.
